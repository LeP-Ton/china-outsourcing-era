## 目标与范围

交付桌面优先的拟真企业管理系统。首版将客户、竞争对手、个体劳动者、竞标、三种合同业务、人员配置、多层服务、应收与工资支付接入同一世界，并通过真实月结驱动风险、舆情和行业排名。

基于需求第二十一节分期。完整猎头业务、灵活用工平台、并购和大语言模型交互进入[后续扩展清单](../../../TODO.md)。

## 验收标准

- 可自定义企业资料，用同一随机种子复现开局。
- 玩家可竞标、签约、招人、配置项目、推进月份，并看到履约、收入、回款和实际支付。
- 派遣、人力外包及专业服务具备不同的交付或合规规则，分包层级与资金路径可查。
- 个体劳动者的薪酬、工作量、公平感、竞争机会与职业状态影响人员变化。
- 18 个导航模块呈现可操作功能或来自模拟的可查询数据。
- 存读档可续玩，存在现金压力及破产路径。
- 自动化验证会计守恒、入职与配置、合规、竞争、确定性和 120 月的多策略模拟。

## 当前有效结论

首版已覆盖 18 个经营模块和完整的采购、交付、结算循环。玩法在本地规则引擎内运行，浏览器使用 IndexedDB 保存进度。默认演示保留六个月的模拟记录，自建企业可从 2026 年 1 月开始。

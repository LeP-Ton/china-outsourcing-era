- Git：空的 `main` 分支，无已有提交和可复用项目

## 实施顺序

1. 使用 React、TypeScript 和 Vite 建立本地 Web 项目。建立独立的种子随机数、市场配置、企业和人物模型。
2. 接通竞标、NPC 采购与招人、合同签署、项目配置、分包、月度结算和应收账款。将合规、人员流动和新闻与模拟状态关联。
3. 实现企业管理界面。导航分经营、交易、组织和治理场景，表格支持筛选、排序与分页。使用明暗主题、统一货币口径、趋势图、状态提示和详情面板。
4. 使用 Web Worker 运行月结、IndexedDB 管理快照和继续游戏。默认总览打开可操作的示例企业，玩家可在企业菜单创建从 2026 年 1 月开始的新公司。
5. 运行浏览器端经营闭环、引擎自动测试，检查多地区、多策略的 120 月表现及 3 万人物单月计算。

## 实施边界

首版按需求中列出的三类主营业务推进。分包采用有界合作链，并以有效交付确认服务费。法定费用、劳动关系和监管处置使用独立的游戏数值模型。

## 界面规范

- 主导航固定在左侧，常用操作位于页首，打开的业务页面可从标签栏返回。窄屏把侧栏收进可展开菜单。
- 浅色界面用白色工作区、浅灰底、深色导航和蓝色主操作。深色主题保留操作状态语义。成功、警示、风险使用文字与颜色共同表达。
- 指标卡对齐标题和值，金额按元或万元展示，业务数据保持统一的货币、百分比和月份格式。账务模块区分合同金额、履约确认金额、已到账金额和应收余额。
- 表格用于批量查阅和操作。对应的数据量较大时提供搜索、排序、分页和人员窗口化渲染。合同方案、用工安排和人员履历从表格打开详情。
- 一般修改即刻显示结果。新建企业、读档和导入前显示对当前自动存档的影响。月结完成显示已确认收入和实际回款。

# 中国外包时代

LabX · GameX 的人力资源企业经营模拟游戏。你可以经营一家人力资源公司，参与招标，招募与培养劳动者，通过劳务派遣、人力外包和专业服务获取收入。合同质量、市场供求、人员流动和客户账期都会改变利润与现金储备。

## 在线游玩

[打开《中国外包时代》](https://lep-ton.github.io/china-outsourcing-era/)。浏览器会在该站点保存当前进度。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

访问终端显示的本地地址。首次打开进入可操作的演示企业，便于查看带有账务和履约历史的经营总览。点击经营总览的「创建企业」选择地区、经营背景和初始资金难度。经营模式包括开放沙盒、5/10/20 年挑战，以及回款寒冬、季节性用工荒、质量优先采购三个一年剧本。相同版本、种子和开局配置可以生成相同的市场。

## 第一个经营月

1. 进入「招投标管理」，比较报价、人力成本、到岗率、账期和准备额度。每月用有限的准备点提交方案，首月可优先尝试两笔各需 1 点的同城试单。提交后在截止月份等待采购评审。
2. 在「合同管理」签署中标项目。进入「招聘管理」录用人员，或在「用工管理」调配已有员工。
3. 在「供应商管理」维护分包关系，在「薪酬社保」设置发薪策略与福利。
4. 点击「推进下月」，系统将核验履约、开具应收、催收已到期账单、支付费用并更新市场。在「财务管理」分别查看利润和实际现金流。
5. 「系统设置」支持手动保存、读取、导出 JSON、导入和恢复演示。游戏会在成功的经营动作后自动保存当前进度。

游戏中的企业、人物和采购均为虚构。费用和用工风险按游戏规则计算。

## 验证

```bash
npm run build
npm test
npm run simulate
```

长期模拟输出每个策略、种子和经济场景下的生存率、利润、市场份额、离职和员工薪资，并检查大规模人物计算。
